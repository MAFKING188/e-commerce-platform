\section{Project Vision}

The objective is to transform a basic CRUD system into a scalable e-commerce platform.

The system must support product browsing, cart management, order processing, and administrative control while being extensible for future integrations.

\subsection{Actors and Roles}

The system defines three primary actors, each with distinct roles and permissions:

\begin{itemize}[noitemsep]

\item \textbf{Guest:} An unauthenticated user who can browse products, view product details, and access authentication features such as login and registration.

\item \textbf{Customer:} An authenticated user who can interact fully with the platform, including managing a shopping cart, placing orders, and submitting product reviews.

\item \textbf{Admin:} A privileged user responsible for managing system data, including products, categories, users, and orders. The admin has elevated permissions enforced through role-based access control.

\end{itemize}

\subsection{Validation Rules}

\subsubsection{Core (Now)}
\begin{itemize}[noitemsep]
\item Product: name (required), price (numeric), stock (integer)
\item User: email (unique, valid), password (min 6 chars)
\item Order: must contain at least one item
\item Cart: quantity must be > 0
\end{itemize}

\subsubsection{Future Enhancements}
\begin{itemize}[noitemsep]
\item Strong password rules
\item Email verification
\item Product SKU uniqueness

\section{Business Constraints \& Edge Cases}

\subsection{Core Constraints (Now)}
\begin{itemize}[noitemsep]
\item Prevent checkout if cart is empty
\item Prevent adding products with zero stock
\item Lock product price at time of order
\end{itemize}

\subsection{Critical Edge Cases}
\begin{itemize}[noitemsep]
\item \textbf{Stock Change During Checkout:} re-validate stock before order creation
\item \textbf{Race Conditions:} use database transactions to avoid overselling
\item \textbf{Duplicate Orders:} prevent double submission (idempotency)
\end{itemize}

\subsection{Future Constraints}
\begin{itemize}[noitemsep]
\item Payment failure handling (retry / cancel)
\item Refund logic and stock restoration
\item Fraud detection mechanisms
\end{itemize}
